# IdealGameOfBiryuziya

Хватит терпеть жирных разработчиков и конские цены на игры! Хватит раздутых системных требований на 150 ГБ ради трёх полигонов! Даёшь пролетарию симулятор целой реальности на любом тостере!

* **Один файл (`reality.rs`)** на чистом Rust без единой внешней библиотеки.
* **Никаких движков, лаунчеров и скрытых майнеров** — вес бинарника меньше одной фотки на телефон.
* **От клеток Конвея до космоса и социума людей** — запускается мгновенно даже на офисном калькуляторе.
